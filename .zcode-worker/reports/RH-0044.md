## Known limits and honest gaps

1. **Preference storage stays browser-local** (`localStorage` per profile key): no cross-device roaming until server-side household preference persistence lands (RH-0043 lineage). The spec's "cached state" concern is covered: preferences survive reload and are honored by freshly fetched (uncached) and cached content alike; reveals are ephemeral by design.
2. **Unscoped API reads serve no watch state** (conservative). The UI always scopes by profile, so users see correct states; direct unscoped API consumers get shield-everything — fail-closed by contract.
3. **Series-level watch state** follows the imported `completed` flag only; a series with watched episodes can still read unknown at series level and stays masked (conservative by design).
4. **Hero synopsis**: the TV hero intentionally renders no synopsis; the Reveal synopsis button is provided for symmetry and future synopsis rendering (revealing is currently equivalent to unmasking eyebrow/backdrop).
5. **Screenshot imagery**: stub serves image tags but no image bytes, so posters show the CSS fallback gradient under the mask states; all assertions target DOM/state, not third-party bytes.
6. **Physical/production checks out of scope**: no Synology, no live Jellyfin, no real household data; live/physical acceptance remains a separate human gate.
